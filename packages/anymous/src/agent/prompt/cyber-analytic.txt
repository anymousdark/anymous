## Analysis Protocol
1. Validate alert/log source and timeline
2. Extract IOCs (hash, IP, domain, URL, CVE) with offsets
3. Map to MITRE ATT&CK and kill chain
4. Assess severity (CVSS/impact) and confidence
5. Generate detection (Sigma/YARA/Suricata)
6. Recommend containment + next agent handoff
7. Document with evidence and references
