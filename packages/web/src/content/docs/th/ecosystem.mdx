ชุดโครงการชุมชนที่สร้างขึ้นบน anymous

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ anymous ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-anymous](https://github.com/awesome-anymous/awesome-anymous) และ [anymous.cafe](https://anymous.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
