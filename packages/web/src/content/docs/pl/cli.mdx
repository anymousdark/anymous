CLI anymous domyślnie uruchamia [TUI](/docs/tui), gdy wywołasz je bez argumentów.

```bash
anymous
```

CLI obsługuje też polecenia opisane na tej stronie, więc możesz używać anymous programowo.

```bash
anymous run "Explain how closures work in JavaScript"
```

---

### tui

Uruchamia interfejs terminalowy (TUI) anymous.

```bash
anymous [project]
```

#### Flagi

| Flaga                                    | Skrót | Opis                                                                    |
| ---------------------------------------- | ----- | ----------------------------------------------------------------------- |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Kontynuuj ostatnią sesję                                                |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | Identyfikator sesji do kontynuowania                                    |
| <nobr><code>{"--fork"}</code></nobr>     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`) |
| <nobr><code>{"--prompt"}</code></nobr>   |       | Monit do użycia                                                         |
| <nobr><code>{"--model"}</code></nobr>    | `-m`  | Model do użycia w formacie dostawca/model                               |
| <nobr><code>{"--agent"}</code></nobr>    |       | Agent do użycia                                                         |
| <nobr><code>{"--port"}</code></nobr>     |       | Port do nasłuchiwania                                                   |
| <nobr><code>{"--hostname"}</code></nobr> |       | Nazwa hosta, do której należy się powiązać                              |

```bash
anymous agent [command]
```

### attach

Dołącz terminal do już działającego serwera backendu anymous uruchomionego za pomocą `serve` lub `web`.

```bash
anymous attach [url]
```

Pozwala to połączyć TUI ze zdalnym backendem anymous. Na przykład:

```bash
# Start the backend server for web/mobile access
anymous web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
anymous attach http://10.20.30.40:4096
```

#### Flagi

| Flaga                                    | Skrót | Opis                                                                                                  |
| ---------------------------------------- | ----- | ----------------------------------------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |       | Katalog roboczy, w którym uruchomić TUI                                                               |
| <nobr><code>{"--continue"}</code></nobr> | `-c`  | Kontynuuj ostatnią sesję                                                                              |
| <nobr><code>{"--session"}</code></nobr>  | `-s`  | Identyfikator sesji do kontynuowania                                                                  |
| <nobr><code>{"--fork"}</code></nobr>     |       | Rozgałęź sesję podczas kontynuowania (użyj z `--continue` lub `--session`)                            |
| <nobr><code>{"--password"}</code></nobr> | `-p`  | Hasło uwierzytelniania podstawowego (domyślnie `ANYMOUS_SERVER_PASSWORD`)                            |
| <nobr><code>{"--username"}</code></nobr> | `-u`  | Nazwa użytkownika uwierzytelniania podstawowego (domyślnie `ANYMOUS_SERVER_USERNAME` lub `anymous`) |

### auth

Zarządzaj danymi uwierzytelniającymi i logowaniem dla dostawców.

```bash
anymous auth [command]
```

---

#### login

anymous integruje się z wieloma dostawcami. Możesz użyć `anymous auth login`, aby skonfigurować klucz API dla dowolnego obsługiwanego dostawcy. Klucze są bezpiecznie przechowywane w `~/.local/share/anymous/auth.json`.

```bash
anymous auth login
```

Podczas uruchamiania anymous ładuje dostawców z pliku poświadczeń, a także ze zmiennych środowiskowych lub pliku `.env` w Twoim projekcie.

---

#### list

Wyświetl listę wszystkich uwierzytelnionych dostawców przechowywanych w pliku poświadczeń.

```bash
anymous auth list
```

Lub skrócona wersja:

```bash
anymous auth ls
```

---

#### logout

Wyloguj się z dostawcy, usuwając go z pliku poświadczeń.

```bash
anymous auth logout
```

### mcp

Zarządzaj serwerami Model Context Protocol (MCP).

```bash
anymous mcp [command]
```

---

#### add

Dodaj serwer MCP do swojej konfiguracji.

```bash

```

To polecenie poprowadzi Cię przez proces dodawania lokalnego lub zdalnego serwera MCP.

---

#### list

Wyświetl listę wszystkich skonfigurowanych serwerów MCP i ich status.

```bash
anymous mcp list
```

Lub skrócona wersja:

```bash
anymous mcp ls
```

---

#### auth

Uwierzytelnij się w serwerze MCP z włączoną funkcją OAuth.

```bash
anymous mcp auth [name]
```

Jeśli nie podasz nazwy serwera, zostaniesz poproszony o wybranie jednego z serwerów wymagających uwierzytelnienia.

Możesz także wyświetlić listę serwerów obsługujących OAuth i ich status uwierzytelnienia.

```bash
anymous mcp auth list
```

Lub skrócona wersja:

```bash
anymous mcp auth ls
```

---

#### logout

Usuń tokeny OAuth dla serwera MCP.

```bash
anymous mcp logout [name]
```

---

#### debug

Debuguj problemy z połączeniem OAuth dla serwera MCP.

```bash
anymous mcp debug <name>
```

### models

Wyświetl listę modeli ze wszystkich skonfigurowanych dostawców.

```bash
anymous models [provider]
```

Pokazuje modele dostępne do użycia w `provider/model`.

Jest to identyfikator modelu, którego używasz w [konfiguracji](/docs/config).

Opcjonalnie możesz podać identyfikator dostawcy, aby filtrować modele według tego dostawcy.

```bash
anymous models anthropic
```

#### Flagi

| Flaga                                   | Opis                                                                            |
| --------------------------------------- | ------------------------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr> | Odśwież pamięć podręczną modeli                                                 |
| <nobr><code>{"--verbose"}</code></nobr> | Bardziej szczegółowe dane wyjściowe modelu (zawiera metadane, takie jak koszty) |

Użyj flagi `--refresh`, aby zaktualizować listę modeli w pamięci podręcznej. Jest to przydatne, gdy dostawca dodał nowe modele, które chcesz zobaczyć w anymous.

```bash
anymous models --refresh
```

### run

Uruchom anymous w trybie nieinteraktywnym, przekazując bezpośrednio prompt.

```bash
anymous run [message..]
```

Jest to przydatne do tworzenia skryptów, automatyzacji lub gdy chcesz wysłać szybkie zapytanie bez uruchamiania TUI. Na przykład:

```bash "anymous run"
anymous run Explain the use of context in Go
```

Można również użyć tego z działającym `anymous serve`, aby uniknąć zimnego startu serwera MCP przy każdym uruchomieniu:

```bash
# Start a headless server in one terminal
anymous serve

# In another terminal, run commands that attach to it
anymous run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

| <nobr><code>{"--session"}</code></nobr>  | `-s`  | Identyfikator sesji do kontynuowania                                                                  |
| <nobr><code>{"--fork"}</code></nobr>     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`)                               |
| <nobr><code>{"--share"}</code></nobr>    |       | Udostępnij sesję po zakończeniu                                                                       |
| <nobr><code>{"--model"}</code></nobr>    | `-m`  | Model do użycia w formacie dostawca/model                                                             |
| <nobr><code>{"--agent"}</code></nobr>    |       | Agent do użycia                                                                                       |

### serve

Uruchom serwer anymous (bez interfejsu) w celu uzyskania dostępu do API. Pełny opis API HTTP znajduje się w [dokumentacji serwera](/docs/server).

```bash
anymous serve
```

Uruchamia to serwer HTTP, który zapewnia dostęp do API anymous bez interfejsu TUI. Ustaw `ANYMOUS_SERVER_PASSWORD`, aby włączyć podstawowe uwierzytelnianie HTTP (domyślna nazwa użytkownika to `anymous`).

#### Flagi

| Flaga                                    | Opis                                       |
| ---------------------------------------- | ------------------------------------------ |
| <nobr><code>{"--port"}</code></nobr>     | Port do nasłuchiwania                      |
| <nobr><code>{"--hostname"}</code></nobr> | Nazwa hosta, do której należy się powiązać |
| <nobr><code>{"--mdns"}</code></nobr>     | Włącz wykrywanie mDNS                      |
| <nobr><code>{"--cors"}</code></nobr>     | Dodatkowe dozwolone źródła CORS            |
